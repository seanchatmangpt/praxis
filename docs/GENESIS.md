**Standing rules for all seven days:**
1. Agents implement; the human authors objective functions and law. Nothing self-authorizes.
2. Every refusal is receipted with reason and salvage. Silent gaps are the only forbidden artifact.
3. Publication is explicit: dry-run before publish, refusal-receipt when a crate is unpublishable (path deps, missing licenses).
4. Each day's receipt chains the previous day's. The week is one auditable object.
