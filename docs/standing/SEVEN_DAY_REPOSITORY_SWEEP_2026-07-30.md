- older architectural precedents were newly invented during this window;
- Praxis application subsystems have already been migrated to every standard.

## Falsifier

The sweep is stale if a searchable in-scope repository has a commit dated
inside the window that introduces a materially distinct standard absent from
the root or subordinate contracts. That commit must be named, classified, and
either admitted or explicitly excluded with rationale.
