## Queries added

All 3 are COUNT-shaped SELECTs (this crate's SPARQL engine typed-refuses `GROUP_CONCAT`/`SAMPLE`
aggregates, per house convention — no ASK query was added either, since the existing SPARQL
execution helpers, `bench::roles::select_rows`/`metric_count`, are wired for SELECT rows only,
and `jira.rs`'s own test asserts ASK queries are refused; reusing the existing helper was chosen
over adding new ASK plumbing), each with a header comment stating exactly what it counts and, for
the two count-of-artifacts-not-count-of-individual-exceptions queries, an explicit note against
overclaiming:

- `crates/cng/queries/metric-soc2-evidenced-controls.rq` — COUNT DISTINCT control points
  (`prov:Plan`) carrying a complete evidentiary record.
- `crates/cng/queries/metric-soc2-exceptions.rq` — COUNT DISTINCT exception-register
  deliverables generated by the Exception Identification phase (NOT a per-exception count).
- `crates/cng/queries/metric-soc2-remediation-status.rq` — COUNT DISTINCT remediation-log
  deliverables generated by the Management Response & Remediation phase.

All 3 run directly over the case-study INSTANCE graph (`prov:`/`skos:`/`dcterms:` vocabulary),
not the Fortune-5 `rwai-bench` OCEL evidence graph those other `metric-*.rq` files read — a
different graph shape by design, disclosed in each query's own header comment.

## `Soc2EvidenceMetrics` (measurement-class separation)

`bench::soc2::compute_evidence_metrics` mirrors `report.rs`'s `ModeledLlmComparison`/
`DerivedScaleExtrapolation` convention: `measurement_class: "SOC2_EVIDENCE_BUNDLE_METRICS"`,
3 measured `u64` counts, and exactly one Rust-computed `f64` ratio
(`derived_exception_register_ratio`) carrying its own machine-readable
`derived_exception_register_ratio_class` field set to the constant
`Soc2EvidenceMetrics::DERIVED_ARITHMETIC` — so a JSON reader (e.g.
`case-study/ocel/evidence-metrics.json`) cannot mistake the one derived field for a fourth
measured SPARQL count.

Measured values on the shipped Solace Cloud instance data: `evidenced_controls: 3`,
`exception_register_artifacts: 1`, `remediation_log_artifacts: 1`,
`derived_exception_register_ratio: 0.3333333333333333` (= 1/3, computed in Rust).

## Divide-by-zero discipline

`soc2_evidence_metrics_measure_the_shipped_case_study_instance_data` also constructs a mutant
instance graph with every `prov:Plan` control-point typing stripped (0 evidenced controls) and
asserts the ratio is the documented `0.0` — never a panic, never a fabricated nonzero value.
