## The fence table

Each subsystem owns exactly one kind of authority. Crossing a fence is the
bug (invariant 6 in `RELEASE_CONTROL.md` Sec. 4 governs how fixes land).

| Subsystem | Owns | Explicitly does NOT own | Fence evidence |
|---|---|---|---|
| GraphLaw (`crates/praxis-graphlaw` via `crates/ggen/src/graph.rs`) | **Meaning and standing** — facts, rules, SHACL/ShEx conformance, denials, standing derivation | Search, execution, artifact writing | Derived facts enter the queryable mirror only through `GraphLawStore::materialize`; standing is law-derived, never asserted (`BREED_ALGORITHM_REGISTRY.md` header; `ontology/rules/breed_standing.n3`) |
| PDDL planner (`bcinr-pddl`, `crates/pddl-index`) | **Search** — finding a legal plan | Deciding what facts mean; executing anything | Consumes only manufactured PDDL8 from admitted facts (`src/mfg.rs::enforce_pddl8`); `wasm4pm-planner` is a separate cross-check lane, not in the standing path (root `Cargo.toml:114-116` comment) |
| POWL (`bcinr-powl`, `crates/powl2-decompose`) | **Workflow shape** — ordering, acyclicity, reachability | Plan search, side effects | `compile_powl` enforces acyclicity + reachability at compile time (`PLANNER_SURFACE.md`) |
| bcinr hot path | **Execution** — deterministic ticking of compiled tapes | Meaning, judgment, evidence content | Runs only compiled `PowlTape`s; every fired atom emits a frame it does not interpret (`src/plan_run.rs`) |
| ggen (`crates/ggen`) | **Manufacturing** — artifacts, reports, code from admitted graphs | Admitting facts, granting standing | `#![deny(unsafe_code)]`, deny `todo!`/`unimplemented!`/`print_stdout` (`crates/ggen/src/lib.rs`); law gates run before render (`sync.rs`) |
| Verifiers (`crates/praxis-lean`, `cargo test`, `mfg::validate`) | **Judgment** — pass/fail on artifacts | Producing artifacts, writing receipts' content | Lean kernel admission with sorry-free enforcement (`crates/praxis-lean/src/no_sorry.rs`); `mfg::validate` must report solvable before receipting |
| Receipts (`bcinr-powl-receipt`, `src/ops.rs`) | **Evidence** — computed, chained, replayable | Judgment (a receipt records; it does not approve) | BLAKE3, genesis-folded, `ts_ns=0` (invariants 2–3, `RELEASE_CONTROL.md` Sec. 4); byte-layout tests in `bcinr-powl-receipt/src/causal_receipt.rs` |

Client boundary: client surfaces (`clients/autonomic-platform/`) sit outside
every fence above — they display standing read-only through the adapter
contract (`CLIENT_ADAPTER_CONTRACT.md`) and own nothing; a client value
without a `{source, ref}` pointer renders UNKNOWN/NON-STANDING, never green.
