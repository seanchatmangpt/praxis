`cng`'s `bench` feature (`crates/cng/src/bench.rs`, 2,229 lines) manufactures a Recursive

## 3. Core invariant — the `G_OCEL = CONSTRUCT_P(G_OBS)` formalism

**Originated in this document.** No existing repo doc uses this notation — confirmed by grep
this session across `docs/CHATMAN_EQUATION.md` and `crates/cng/BENCHMARK.md` (zero hits). It is
introduced here as a benchmark-scoped refinement of `A = μ(O*)` (cited verbatim from
`docs/CHATMAN_EQUATION.md:4`: "Chatman Engine is the concrete realization of μ in the Chatman
Equation `A = μ(O*)`, `R = receipt(A)`"), not a replacement for it:

- `G_OBS` — the observation store (oxigraph), populated only from disk templates
  (`crates/cng/templates/bench-observation-*.template.ttl`); this is the benchmark's `O*`
  (admitted observation).
- `P` — the fixed, disk-resident set of SPARQL CONSTRUCT queries
  (`crates/cng/queries/*.construct.rq`), generated by `packs/ocel-bench-pack` from
  `crates/praxis-graphlaw/ontologies/core/ocel2.ttl`; this is the benchmark's `μ` (lawful
  manufacturing transformation), scoped specifically to evidence-graph construction.
- `G_OCEL` — the resulting OCEL 2.0 evidence graph; this is the benchmark's `A` (artifact with
  standing), and `ocel_graph_digest` (BLAKE3 of its sorted N-Triples serialization) is its `R`
  (receipt proving consequence).

Every `RunReport` headline field is a SELECT over `G_OCEL`, never asserted directly — this is
the mechanism, not a metaphor, behind the "evidence graph is the authority" reconcile gate
(`bench.rs` ~1860-1887).

## 4. Object model

`RunReport` (measured), `VerifyReport` (replay), `TelemetryCounters` (non-authoritative,
reconciled against the graph). Digests: `powl_digest` (per-set manufacture digest, recorded in
`digests.json`), `ocel_graph_digest` (`RunReport` field), `sparql_result_digest` (`RunReport`
field, hashes the full ordered SELECT results — `bench.rs`, computed alongside
`ocel_graph_digest`). No single manifest file names all four; see Sec. 15 gap below and `PRD.md`
row 8.

## 10. Dataflow

1. `generate` renders disk templates into an observation store (no inline `format!` Turtle, no
   inline SPARQL, per `crates/cng/BENCHMARK.md` line 12).
2. `run` CONSTRUCTs the OCEL evidence graph (Sec. 3 formalism), computes `ocel_graph_digest` and
   `sparql_result_digest`, runs the Datalog role layer (Sec. 6), manufactures hierarchical POWL
   (Sec. 7), executes via `runner::validate_run_hierarchical`, and applies the reconcile gate
   (Sec. 3/Component table) before returning a `MEASURED_CNG_RESULT` `RunReport`.
3. `verify` (`bench.rs` ~2050-2115) re-derives and checks the POWL manufacture digest only for a
   sampled subset of sets, and re-parses/shape-validates a sampled subset of exported `.ttl`
   artifacts from disk. It does **not** recompute or compare `ocel_graph_digest` or
   `sparql_result_digest` — `PRD.md` row 4, PARTIAL not ALIVE.
4. Bundle path portability bug: `digests.json` keys are `dir.display().to_string()` captured at
   `run` time; `verify()` (`bench.rs:2064`) reads them back verbatim without rejoining against
   its own `--dir` argument — `PRD.md` row 3, BLOCKED for any third-party-auditor-replay claim.

## 13. Market architecture

- **"5M workers" / "8⁵ nodes"** — DERIVED_ARITHMETIC, per `crates/cng/BENCHMARK.md` line 96,
  never a measurement; this release additionally corrects the underlying formula: attachment
  count at depth n is `(8^n − 8)/7`, not `8^n` (`PRD.md` row 6). Any external claim using `8^n`
  for attachment/edge counts is wrong and superseded by this correction.
- **PQC** — REFUSED this release (`PRD.md` row 11); classical ed25519 signing exists in
  `crates/praxis-core/src/signing.rs` (`sign_chain_hash`/`verify_chain_hash`, `signed` feature)
  as the actual near-term seam, with zero wiring into `cng` today.
- **"Verified"/"independently replayable"** — must be scoped to "POWL manufacture digest,
  sampled subset" per `PRD.md` row 2/4, never unscoped "fully verified."

## 14. Adversarial architecture

The reconcile gate (`bench.rs` ~1860-1887) is the benchmark's built-in adversarial check against
its own telemetry: any disagreement between Rust counters and the SPARQL-derived graph numbers
is a hard refusal (`CngRefusal::HardcodingSuspicion`), not a warning. This release's own
adversarial finding — the `verify()` path-portability bug (Sec. 10.4) — was found by tracing
`digests.json` key construction against `verify()`'s read path this session, not asserted from a
prior summary.

`CngRefusal` (`crates/cng/src/powl.rs:37-111`, `CNG_R01`-`CNG_R10`) has no exhaustiveness
registry — open for extension. `CNG_R08 Nondeterminism` ("repeated manufacture produced
different bytes") is the wrong reuse target for an auditor-digest-mismatch refusal: that is
same-producer re-manufacture drift, semantically distinct from a third-party integrity mismatch
against a previously recorded digest. This release recommends a genuine new `CNG_R11
AuditMismatch` variant as PLANNED work (PROJ-605), not implemented yet.
