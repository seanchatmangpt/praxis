# No Self-Graded Victory

**Summary**: The agent that did the work may not declare it done; only an independent auditor
issues the verdict.

**Source evidence**: Fable Operating Constitution, Absolute Doctrine item 6 and Victory
Conditions (`docs/chatman-engine/FABLE_OPERATING_CONSTITUTION.md`).

**Why it matters**: Implementers systematically overclaim; self-graded "done" reports have
repeatedly masked vacuous tests, stub implementations, and unverified receipts.

**Future instruction**: End every run by handing artifacts to an independent auditor step
(work-order step 18). Report your own status only as verified/not-verified/skipped items,
never as a verdict.
