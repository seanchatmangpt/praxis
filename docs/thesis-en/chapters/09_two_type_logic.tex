\chapter{Two-Type Logic and Dependent Type Theory}
\label{ch:two_type_logic}

\section{Introduction}

In this chapter, we develop a rigorous mathematical foundation for the semantic interpretation of Two-Type Logic via Intensional Martin-L\"of Dependent Type Theory (MLTT). Our formulation extends standard models by incorporating a formalized hierarchy of universes $\mathcal{U}_i$ and an explicit propositional reflection system. The theoretical underpinnings presented herein are essential for addressing the structural deficiencies noted in earlier formulations of our algebraic logic frameworks. We deploy advanced dependently typed constructs and utilize standard rules of deduction in the style of natural deduction, formalized with the \texttt{mathpartir} package.

The core motivation of this chapter is to provide an unabridged formalization of the deductive system governing Two-Type Logic. We demonstrate not only the basic type formers ($\Pi$, $\Sigma$, $\mathrm{Id}$, $W$, etc.) but also their interactions with modal operators denoting rigid (necessary) and contingent truths. This yields a dual-context type theory capable of resolving complex metaphysical invariants at compile-time through definitional equality and path induction.

\section{Syntax and Judgments of the Core Theory}

We define the syntax of our language as follows. We assume a countably infinite set of variables $\mathcal{V}$. The pre-terms of the theory are given by the grammar:
\begin{align*}
A, B, a, b ::= & \ x \mid \mathcal{U}_i \mid \Pi(x:A).B \mid \lambda x.a \mid a(b) \mid \Sigma(x:A).B \mid (a, b) \mid \pi_1(a) \mid \pi_2(a) \\
& \mid \mathrm{Id}_A(a, b) \mid \mathrm{refl}_a \mid \mathrm{J}(a, b, p, C, d) \mid W(x:A).B \mid \sup(a, f) \mid \mathrm{wrec}(z, C, e)
\end{align*}

The fundamental judgments of MLTT are of four forms:
\begin{enumerate}
    \item $\Gamma \vdash \text{ctx}$ : $\Gamma$ is a well-formed context.
    \item $\Gamma \vdash A : \mathcal{U}_i$ : $A$ is a well-formed type in universe $\mathcal{U}_i$.
    \item $\Gamma \vdash a : A$ : $a$ is a well-typed term of type $A$.
    \item $\Gamma \vdash a \equiv b : A$ : $a$ and $b$ are definitionally equal terms of type $A$.
\end{enumerate}

\begin{definition}[Context Formation and Weakening]
The formation of contexts is given by the following structural rules:
\begin{mathpar}
\inferrule*[right=Ctx-Emp]{ }{ \cdot \vdash \text{ctx} }

\inferrule*[right=Ctx-Ext]{ \Gamma \vdash A : \mathcal{U}_i \\ x \notin \mathrm{dom}(\Gamma) }{ \Gamma, x : A \vdash \text{ctx} }

\inferrule*[right=Var]{ \Gamma, x : A, \Gamma' \vdash \text{ctx} }{ \Gamma, x : A, \Gamma' \vdash x : A }

\inferrule*[right=Weaken]{ \Gamma \vdash a : B \\ \Gamma \vdash A : \mathcal{U}_i \\ x \notin \mathrm{dom}(\Gamma) }{ \Gamma, x : A \vdash a : B }
\end{mathpar}
\end{definition}

\section{Dependent Function Types ($\Pi$-types)}

\begin{definition}[$\Pi$-Type Formulation]
The $\Pi$-type represents dependent functions, generalizing implication and universal quantification.

\begin{mathpar}
\inferrule*[right=$\Pi$-Form]{ \Gamma \vdash A : \mathcal{U}_i \\ \Gamma, x : A \vdash B : \mathcal{U}_j }{ \Gamma \vdash \Pi(x:A).B : \mathcal{U}_{\max(i, j)} }

\inferrule*[right=$\Pi$-Intro]{ \Gamma, x : A \vdash b : B }{ \Gamma \vdash \lambda x.b : \Pi(x:A).B }

\inferrule*[right=$\Pi$-Elim]{ \Gamma \vdash f : \Pi(x:A).B \\ \Gamma \vdash a : A }{ \Gamma \vdash f(a) : B[a/x] }

\inferrule*[right=$\Pi$-Comp]{ \Gamma, x : A \vdash b : B \\ \Gamma \vdash a : A }{ \Gamma \vdash (\lambda x.b)(a) \equiv b[a/x] : B[a/x] }

\inferrule*[right=$\Pi$-Ext]{ \Gamma \vdash f : \Pi(x:A).B \\ \Gamma \vdash g : \Pi(x:A).B \\ \Gamma, x : A \vdash f(x) \equiv g(x) : B }{ \Gamma \vdash f \equiv g : \Pi(x:A).B }
\end{mathpar}
\end{definition}

\begin{lemma}[Function Extensionality via Paths]
\label{lem:funext}
While the definitional $\Pi$-Ext rule holds definitionally in some variants of Extensional Type Theory, in Intensional Type Theory, function extensionality is posited as an axiom or derived from Univalence. For any $f, g : \Pi(x:A).B$, if there exists a term $p : \Pi(x:A).\mathrm{Id}_{B(x)}(f(x), g(x))$, then there exists a term $\mathsf{funext}(p) : \mathrm{Id}_{\Pi(x:A).B}(f, g)$.
\end{lemma}

\begin{proof}
Assuming the Univalence Axiom for the universe $\mathcal{U}_i$. We construct the proof using the standard equivalence between paths in the $\Pi$-type and pointwise paths. Let $p : \Pi(x:A).\mathrm{Id}_{B(x)}(f(x), g(x))$. Define a map:
\[
h : A \to \Sigma(y:B(x)).\mathrm{Id}_{B(x)}(f(x), y)
\]
given by $h(x) = (f(x), \mathrm{refl}_{f(x)})$. Under the first projection $\pi_1 \circ h \equiv f$. Univalence ensures that for any $x : A$, the total space $\Sigma(y:B(x)).\mathrm{Id}_{B(x)}(f(x), y)$ is contractible (a singleton). The space of dependent functions into a contractible family is itself contractible. Therefore, there is a unique path between any two functions mapping into this space. Thus, the existence of pointwise paths $p$ induces a unique path between $f$ and $g$ in the $\Pi$-type, yielding $\mathsf{funext}(p)$.
\end{proof}

\section{Dependent Pair Types ($\Sigma$-types)}

\begin{definition}[$\Sigma$-Type Formation and Elimination]
The $\Sigma$-type represents dependent pairs, generalizing conjunction and existential quantification.
\begin{mathpar}
\inferrule*[right=$\Sigma$-Form]{ \Gamma \vdash A : \mathcal{U}_i \\ \Gamma, x : A \vdash B : \mathcal{U}_j }{ \Gamma \vdash \Sigma(x:A).B : \mathcal{U}_{\max(i,j)} }

\inferrule*[right=$\Sigma$-Intro]{ \Gamma \vdash a : A \\ \Gamma \vdash b : B[a/x] }{ \Gamma \vdash (a, b) : \Sigma(x:A).B }

\inferrule*[right=$\Sigma$-Elim-1]{ \Gamma \vdash p : \Sigma(x:A).B }{ \Gamma \vdash \pi_1(p) : A }

\inferrule*[right=$\Sigma$-Elim-2]{ \Gamma \vdash p : \Sigma(x:A).B }{ \Gamma \vdash \pi_2(p) : B[\pi_1(p)/x] }

\inferrule*[right=$\Sigma$-Comp-1]{ \Gamma \vdash a : A \\ \Gamma \vdash b : B[a/x] }{ \Gamma \vdash \pi_1(a, b) \equiv a : A }

\inferrule*[right=$\Sigma$-Comp-2]{ \Gamma \vdash a : A \\ \Gamma \vdash b : B[a/x] }{ \Gamma \vdash \pi_2(a, b) \equiv b : B[a/x] }
\end{mathpar}
\end{definition}

\begin{theorem}[Axiom of Choice in MLTT]
\label{thm:ac_mltt}
In Martin-L\"of Type Theory, the type-theoretic Axiom of Choice is not merely an axiom, but a derivable theorem due to the constructive nature of the existential quantifier ($\Sigma$-type). Specifically, for any sets $A$ and $B : A \to \mathcal{U}$ and a relation $R : \Pi(x:A). B(x) \to \mathcal{U}$, the following type is inhabited:
\[
AC : (\Pi(x:A). \Sigma(y:B(x)). R(x, y)) \to \Sigma(f:\Pi(x:A).B(x)). \Pi(x:A).R(x, f(x))
\]
\end{theorem}

\begin{proof}
The proof proceeds by explicit construction of the proof term. Let $g : \Pi(x:A). \Sigma(y:B(x)). R(x, y)$. This term $g$ is a function taking any $x : A$ to a pair $(y, r)$ where $y : B(x)$ and $r : R(x, y)$.

We must construct a term in $\Sigma(f:\Pi(x:A).B(x)). \Pi(x:A).R(x, f(x))$.
We define the function $f$ by:
\[
f \equiv \lambda x. \pi_1(g(x))
\]
By the typing rules for $\Pi$-Elim and $\Sigma$-Elim-1, for any $x : A$, $g(x) : \Sigma(y:B(x)). R(x, y)$, and thus $\pi_1(g(x)) : B(x)$. Hence, $f : \Pi(x:A).B(x)$.

Next, we define the proof term $p$ establishing that $f$ satisfies the relation $R$:
\[
p \equiv \lambda x. \pi_2(g(x))
\]
For any $x : A$, $\pi_2(g(x)) : R(x, \pi_1(g(x)))$. Since $\pi_1(g(x))$ is definitionally equal to $f(x)$, it follows that $\pi_2(g(x)) : R(x, f(x))$. Thus $p : \Pi(x:A).R(x, f(x))$.

Finally, we pair $f$ and $p$ to inhabit the $\Sigma$-type. The complete proof term is:
\[
ac\_proof \equiv \lambda g. (\lambda x. \pi_1(g(x)), \lambda x. \pi_2(g(x)))
\]
\end{proof}

To illustrate the rigorous nature of this derivation, we provide the derivation tree for the construction of $f$:
\begin{mathpar}
\inferrule*{
  \inferrule*{
    \Gamma, g, x \vdash g : \Pi(x:A). \Sigma(y:B(x)). R(x,y) \\
    \Gamma, g, x \vdash x : A
  }{ \Gamma, g, x \vdash g(x) : \Sigma(y:B(x)). R(x,y) }
}{ \Gamma, g, x \vdash \pi_1(g(x)) : B(x) }
\end{mathpar}
Applying $\Pi$-Intro binds $x$ to yield $\lambda x. \pi_1(g(x))$.

\section{Identity Types and Path Induction}

The identity type $\mathrm{Id}_A(a, b)$ or $a =_A b$ is the cornerstone of propositional equality.

\begin{definition}[Identity Type Formation and Introduction]
\begin{mathpar}
\inferrule*[right=Id-Form]{ \Gamma \vdash A : \mathcal{U}_i \\ \Gamma \vdash a : A \\ \Gamma \vdash b : A }{ \Gamma \vdash \mathrm{Id}_A(a, b) : \mathcal{U}_i }

\inferrule*[right=Id-Intro]{ \Gamma \vdash a : A }{ \Gamma \vdash \mathrm{refl}_a : \mathrm{Id}_A(a, a) }
\end{mathpar}

The eliminator for the identity type, known as path induction or the $J$-eliminator, operates on type families dependent on two endpoints and a path:
\begin{mathpar}
\inferrule*[right=Id-Elim]{
  \Gamma, x:A, y:A, p:\mathrm{Id}_A(x,y) \vdash C(x,y,p) : \mathcal{U}_j \\
  \Gamma, x:A \vdash d(x) : C(x,x,\mathrm{refl}_x) \\
  \Gamma \vdash a : A \\ \Gamma \vdash b : A \\
  \Gamma \vdash q : \mathrm{Id}_A(a,b)
}{ \Gamma \vdash \mathrm{J}(C, d, a, b, q) : C(a, b, q) }
\end{mathpar}

The computation rule for $J$ states that applying path induction to reflexivity yields the base case:
\begin{mathpar}
\inferrule*[right=Id-Comp]{
  \Gamma, x:A, y:A, p:\mathrm{Id}_A(x,y) \vdash C : \mathcal{U}_j \\
  \Gamma, x:A \vdash d : C(x,x,\mathrm{refl}_x) \\
  \Gamma \vdash a : A
}{ \Gamma \vdash \mathrm{J}(C, d, a, a, \mathrm{refl}_a) \equiv d(a) : C(a, a, \mathrm{refl}_a) }
\end{mathpar}
\end{definition}

\begin{lemma}[Transitivity of Identity]
\label{lem:transitivity}
For any $A : \mathcal{U}_i$ and elements $a, b, c : A$, if there exist paths $p : a =_A b$ and $q : b =_A c$, then there exists a concatenated path $p \cdot q : a =_A c$.
\end{lemma}

\begin{proof}
We construct this using path induction on $q$. We wish to define a function $trans : \Pi(a,b,c:A). (a =_A b) \to (b =_A c) \to (a =_A c)$.
Fix $a, b, c : A$ and let $p : a =_A b$. We define a motive (family) $C$ for path induction on $q$:
\[
C(x, y, r) \equiv (a =_A x) \to (a =_A y)
\]
Here $x, y : A$ and $r : x =_A y$. Note that $C(b, c, q) \equiv (a =_A b) \to (a =_A c)$.
To use $J$, we must provide a base case $d(x) : C(x, x, \mathrm{refl}_x)$.
$C(x, x, \mathrm{refl}_x) \equiv (a =_A x) \to (a =_A x)$. We simply provide the identity function:
\[
d(x) \equiv \lambda p'. p'
\]
Applying $J$ yields:
\[
\mathrm{J}(C, (\lambda x. \lambda p'. p'), b, c, q) : (a =_A b) \to (a =_A c)
\]
Applying this to our path $p$ yields the concatenated path $p \cdot q : a =_A c$.
\end{proof}

\section{Well-Founded Trees ($W$-types)}

To handle arbitrary inductive structures without adding ad-hoc rules for each datatype, we introduce $W$-types, representing well-founded trees (or initial algebras of polynomial functors).

\begin{definition}[$W$-Type Rules]
\begin{mathpar}
\inferrule*[right=$W$-Form]{ \Gamma \vdash A : \mathcal{U}_i \\ \Gamma, x : A \vdash B : \mathcal{U}_i }{ \Gamma \vdash W(x:A).B : \mathcal{U}_i }

\inferrule*[right=$W$-Intro]{ \Gamma \vdash a : A \\ \Gamma \vdash f : B[a/x] \to W(x:A).B }{ \Gamma \vdash \sup(a, f) : W(x:A).B }
\end{mathpar}

The $W$-elimination rule captures structural induction over trees:
\begin{mathpar}
\inferrule*[right=$W$-Elim]{
  \Gamma, w:W(x:A).B \vdash C(w) : \mathcal{U}_j \\
  \Gamma, a:A, f:B[a/x] \to W(x:A).B, g:\Pi(v:B[a/x]). C(f(v)) \vdash e(a, f, g) : C(\sup(a,f)) \\
  \Gamma \vdash w : W(x:A).B
}{ \Gamma \vdash \mathrm{wrec}(w, C, e) : C(w) }
\end{mathpar}
\end{definition}

For example, the natural numbers $\mathbb{N}$ can be encoded as a $W$-type by choosing $A = \mathbf{2}$ (a boolean type for the two constructors: zero and successor) and $B(\text{zero}) = \mathbf{0}$ (empty type, zero has no subtrees), $B(\text{succ}) = \mathbf{1}$ (unit type, successor has exactly one subtree).

\section{Two-Type Logic Isomorphism and Modalities}

We now extend Intensional MLTT by distinguishing two fundamental modalities, $\lozenge$ and $\square$, operating over our universes, resulting in the semantic scaffolding for Two-Type Logic. This logic handles necessary (rigid) truths and contingent (ephemeral) truths simultaneously.

\begin{definition}[Modal Dual-Context]
We define a structurally distinct context $\Delta$ for necessarily true propositions (valid in all possible worlds/states), and $\Gamma$ for contingent truth. Judgments take the form:
\[
\Delta; \Gamma \vdash a : A
\]
Meaning $a$ is of type $A$ assuming rigid context $\Delta$ and contingent context $\Gamma$.
\end{definition}

The necessity modality $\square$ internalizes the rigid context.
\begin{mathpar}
\inferrule*[right=$\square$-Form]{ \Delta; \Gamma \vdash A : \mathcal{U}_i }{ \Delta; \Gamma \vdash \square A : \mathcal{U}_i }

\inferrule*[right=$\square$-Intro]{ \Delta; \cdot \vdash a : A }{ \Delta; \Gamma \vdash \square a : \square A }

\inferrule*[right=$\square$-Elim]{ \Delta; \Gamma \vdash m : \square A \\ \Delta, x:A; \Gamma \vdash b : B }{ \Delta; \Gamma \vdash \text{let } \square x = m \text{ in } b : B }
\end{mathpar}

The $\square$-Intro rule requires the contingent context to be empty (denoted by $\cdot$), enforcing that a necessity proof cannot depend on contingent facts.

\begin{lemma}[Modal Substitution]
If $\Delta; \cdot \vdash a : A$ and $\Delta, x:A; \Gamma \vdash b : B$, then $\Delta; \Gamma \vdash b[a/x] : B[a/x]$.
\end{lemma}

\begin{proof}
By structural induction on the derivation of $b : B$. In the base case where $b$ is a variable from $\Delta$, say $x$, then $b[a/x] = a$. Since $\Delta; \cdot \vdash a : A$, we can weaken the contingent context to obtain $\Delta; \Gamma \vdash a : A$, as required by the inference rules. If $b$ is a variable from $\Gamma$, the substitution does not affect it, and the judgment holds trivially. For inductive steps, the substitution distributes over all term constructors (e.g., $\Pi$, $\Sigma$).

The only non-trivial case is $\square$-Intro. Suppose the derivation ends in:
\begin{mathpar}
\inferrule*{ \Delta, x:A; \cdot \vdash c : C }{ \Delta, x:A; \Gamma \vdash \square c : \square C }
\end{mathpar}
By the inductive hypothesis applied to the premise, substituting $a$ for $x$ yields $\Delta; \cdot \vdash c[a/x] : C[a/x]$. We can then safely apply $\square$-Intro to obtain $\Delta; \Gamma \vdash \square(c[a/x]) : \square(C[a/x])$, which perfectly matches the required structure since substitution commutes with the $\square$ constructor.
\end{proof}

\begin{theorem}[Completeness of Two-Type Semantics]
\label{thm:two_type_completeness}
Let $\mathcal{M}$ be a presheaf category model interpreting $\Delta$. For every valid judgment in Two-Type Logic $\Delta; \Gamma \vDash A$, there is a corresponding term assignment in MLTT extended with the $\square$ modality.
\end{theorem}
\begin{proof}
The proof proceeds by exhibiting a syntactic translation $\llbracket - \rrbracket$ from the modal logic into a Category with Families (CwF) equipped with an adjunction $F \dashv G$ modeling the modalities. We show that for every structural rule in the dual-context system, the adjunction preserves the typing judgments.

Specifically, the $\square$ type constructor is modeled by the right adjoint $G : \mathcal{C} \to \mathcal{D}$. The $\square$-Intro rule corresponds to the unit of the adjunction $\eta : \text{id} \Rightarrow G F$, while the $\square$-Elim rule corresponds to the universal property of the counit $\varepsilon : F G \Rightarrow \text{id}$. The empty context requirement in $\square$-Intro maps directly to the action of the comonadic core of the adjunction.

By categorical equivalence, the semantic validity in the presheaf model guarantees the existence of a corresponding categorical morphism, which via the internal language theorem, yields a valid syntax tree in the extended dependent type theory. This implies completeness of the deductive system with respect to the Two-Type semantics.
\end{proof}

\section{Advanced Typing Derivations in Two-Type Logic}

We conclude this chapter with a massive typing derivation illustrating the deep interaction between $\Sigma$-types, identity types, and the Two-Type modalities.

Consider the following deep invariant: \textit{The existence of a reflexive path is a necessary truth independent of contingent local contexts.} Formally, we derive a term inhabiting the type:
\[
\square (\Sigma(x:A). \mathrm{Id}_A(x, x))
\]
Assume a rigid context $\Delta$ containing at least one element $x : A$, meaning $\Delta \equiv x:A$.

\begin{mathpar}
\inferrule*[right=$\square$-I]{
  \inferrule*[right=$\Sigma$-I]{
    \inferrule*[right=Var]{ \Delta; \cdot \vdash \text{ctx} }{ \Delta; \cdot \vdash x : A }
    \\
    \inferrule*[right=Id-I]{
      \inferrule*[right=Var]{ \Delta; \cdot \vdash \text{ctx} }{ \Delta; \cdot \vdash x : A }
    }{ \Delta; \cdot \vdash \mathrm{refl}_x : \mathrm{Id}_A(x, x) }
  }{ \Delta; \cdot \vdash (x, \mathrm{refl}_x) : \Sigma(y:A). \mathrm{Id}_A(x, y) }
}{ \Delta; \Gamma \vdash \square (x, \mathrm{refl}_x) : \square (\Sigma(y:A). \mathrm{Id}_A(x, y)) }
\end{mathpar}

To further establish the power of path induction within a modal context, consider the derivation for mapping a contingent equality into a contingent context using a rigid function $f : \square (A \to B)$. We want to derive:
\[
\Delta, f : \square (A \to B); \Gamma, x:A, y:A, p:\mathrm{Id}_A(x,y) \vdash \mathrm{ap}_f(p) : \mathrm{Id}_B(f(x), f(y))
\]
Let $\Delta' \equiv \Delta, f : \square (A \to B)$ and $\Gamma' \equiv \Gamma, x:A, y:A, p:\mathrm{Id}_A(x,y)$.

\begin{mathpar}
\inferrule*[right=Let-$\square$]{
  \inferrule*[right=Var]{ }{ \Delta'; \Gamma' \vdash f : \square (A \to B) }
  \\
  \inferrule*[right=Id-Elim]{
    \inferrule*[right=Var]{ }{ \Delta', \hat{f} : A \to B; \Gamma', z:A \vdash \mathrm{refl}_{\hat{f}(z)} : \mathrm{Id}_B(\hat{f}(z), \hat{f}(z)) }
    \\
    \dots \text{ (type formation bounds)}
  }{ \Delta', \hat{f} : A \to B; \Gamma' \vdash \mathrm{J}(\dots) : \mathrm{Id}_B(\hat{f}(x), \hat{f}(y)) }
}{ \Delta'; \Gamma' \vdash \text{let } \square \hat{f} = f \text{ in } \mathrm{J}(\dots) : \mathrm{Id}_B(f(x), f(y)) }
\end{mathpar}

This derivation unpacks the rigid function $f$ into a standard functional term $\hat{f}$ via $\square$-Elim, then uses standard path induction ($J$) on the contingent path $p$. This demonstrates that while the function's definition is rigid (necessary), its application to contingent paths remains perfectly well-typed within the contingent fragment of the dual-context system.
