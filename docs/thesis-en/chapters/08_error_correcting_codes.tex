\chapter{Error-Correcting Codes on Graphs}
\label{ch:error_correcting_codes}

\section{Introduction to Graph-Based Codes}
Error-correcting codes on graphs represent a major paradigm shift in coding theory, enabling highly efficient iterative decoding algorithms that allow transmission rates to approach the Shannon capacity limit. This chapter explores both the classical use of graphs to define codes and the newer area of error-correcting graph codes where the data itself is a graph structure.

\section{Sparse Graph Codes}
In traditional coding theory, graph representations such as bipartite graphs (Tanner graphs) have been fundamental. Low-Density Parity-Check (LDPC) codes are perhaps the most famous example. These codes are defined by sparse bipartite graphs where one set of nodes represents the transmitted bits and the other represents parity-check constraints. Their sparsity ensures that the iterative message-passing decoding algorithms (such as Belief Propagation) can be executed in linear time.

Other prominent examples include trellis codes, which are visualized and decoded using paths through a directed graph, and cycle codes, where the parity-check matrix is derived from the incidence matrix of a graph.

\section{Error-Correcting Graph Codes}
A recent and distinct area of study within combinatorics focuses on codes where the messages themselves are graphs. In this framework, an error-correcting graph code is defined as a family of graphs on a fixed set of $n$ vertices. The "distance" between two graphs is determined by how many vertex neighborhoods must be significantly modified to transform one graph into the other. This serves as a generalization of the Hamming distance for binary strings and bridges classical coding theory with extremal combinatorics.

\section{Quantum Codes and Graphs}
Graph-based codes also find applications in quantum computing. Quantum Error-Correcting Codes (QECC) often utilize circulant graphs and their multidimensional generalizations to protect against quantum decoherence. These constructions yield high-performing code parameters that are crucial for reliable quantum information storage and processing.
