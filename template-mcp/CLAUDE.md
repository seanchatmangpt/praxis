# {{project-name}}-mcp — MCP Server Guide

MCP (Model Context Protocol) server exposing `{{project-name}}` capabilities
as callable tools. Transport: stdio (stdin/stdout). The MCP host (Claude Desktop,
a CLI harness, etc.) launches this binary and speaks JSON-RPC over its stdio.

---

## Adding a New Tool

1. **Create** `src/tools/<name>.rs` with a `#[tool(tool_box)]` struct impl.
2. **Export** it in `src/tools/mod.rs`.
3. **Wire** it into `ToolSet` in `src/tools/mod.rs`.
4. **Add unit tests** in the same file (`#[cfg(test)]`).

Minimal new tool:
```rust
// src/tools/my_tool.rs
use rmcp::{tool, ServerHandler, ToolError};
use crate::shared_args::{CommonResponse, TimeWindowArgs};
use serde::Serialize;

#[derive(Debug, Serialize)]
pub struct MyResult { pub value: String }

#[derive(Debug, Default, Clone)]
pub struct MyTool;

#[tool(tool_box)]
impl MyTool {
    #[tool(description = "Do the thing.")]
    async fn do_thing(&self, #[tool(description = "Window")] args: TimeWindowArgs)
    -> Result<String, ToolError>
    {
        let resp = CommonResponse::ok(MyResult { value: "done".into() });
        Ok(serde_json::to_string_pretty(&resp).unwrap())
    }
}

#[tool(tool_box)]
impl ServerHandler for MyTool {}
```

## House Patterns

### `TimeWindowArgs` (mandatory for historical queries)

Every tool that queries over a time range must accept `TimeWindowArgs`:

```rust
#[derive(Deserialize)]
pub struct TimeWindowArgs {
    pub hours: u32,   // default 24
    pub limit: usize, // default 1000
}
```

Import from `crate::shared_args`. Do not redefine per-tool.

### `CommonResponse<T>` (mandatory for all responses)

Every tool response must be wrapped in `CommonResponse<T>`. Rules:
- `passed: bool` — **always present**, even on error (CI gate field)
- `result_hash: String` — BLAKE3 hex digest of `serde_json::to_vec(&data)`
- `data: Option<T>` — payload, `null` on error
- `error: Option<String>` — message, `null` on success

`CommonResponse::ok(data)` computes `result_hash` automatically.
`CommonResponse::err(msg)` sets `passed = false`.

**Never** return a bare struct — always wrap in `CommonResponse`.

### BLAKE3 integrity

`result_hash` proves the response was generated by this server and not tampered
with in transit. Callers can verify: `blake3(json_encode(data)) == result_hash`.

## Running

```bash
# Start the server (stdio transport — used by MCP hosts)
cargo run --bin {{project-name}}-mcp

# Run unit tests
cargo test --all-features

# CI gate
cargo fmt --check && cargo clippy -- -D warnings && cargo test
```

## Configuration

The server reads `RUST_LOG` for log level (logs go to **stderr** — stdout is the
MCP transport):

```bash
RUST_LOG=debug cargo run --bin {{project-name}}-mcp
```
